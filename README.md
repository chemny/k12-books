# ChinaK12BookDownLoader

> **国家中小学智慧教育平台 K12 教材可视化批量下载器与版本管理系统**  
> 界面精简直观、极简暗黑质感，支持按学段/学科/版本多维级联筛选、**一键全选当前筛选结果批量下载**、**实时下载管理器抽屉（带速率与进度）**、**本地同名版本跳过**以及**官方下架旧版教材安全自动归档至 `History/` 镜像目录**。

---

## 🌟 核心特性与改进

1. **强制指定下载根目录（China12Books）**：
   - 顶部提供醒目的目录配置栏，默认绑定或自由选择你的课本存放根目录；
   - **未设置目录时强制禁止下载**并提供高亮预警，避免散落下载到未预期路径。
2. **一键全量 / 筛选结果批量下载**：
   - 不再受限于“仅能下载当前页数十条”；
   - 点击 **“全选筛选结果 (共 X 本)”**，无论是筛选出的 240 本初中数学还是全量 3200+ 本，均可一键全部加入下载队列。
3. **右侧实时下载管理器（任务抽屉面板）**：
   - 点击顶部 **“📥 下载列表”** 即可滑出半透明磨砂抽屉；
   - 实时显示：**排队中、下载中、下载速度（MB/s）、进度条、已完成、失败重试**；
   - 彻底解决“点击下载没有任何反馈反应”的问题。
4. **同名版本秒级跳过**：
   - 包含版本号（如 `[2024修订版]`、`[2022修订版]`）的文件名；
   - 本地已存在且版本大小相符时，下载队列会自动标记为 `已存在(跳过)`，不耗费任何重复流量。
5. **历史版本安全归档至 `History/` 镜像目录**：
   - 当官方平台更新换代或移除某本旧版教材时，点击 **“📦 历史版本审计与归档”**；
   - 系统自动将不在当前官方有效清单中的旧版课本，剪切移动至 `History/` 对应的子目录下；
   - 保证主目录永远只有最新正版，且历史版本完整保留在镜像目录不丢失。

## 🚀 启动与使用方式

### 方式一：Web 模式（推荐，零配置秒开）

依赖仅需 Python 3 + `requests`：

```bash
cd ChinaK12BookDownLoader
python3 server.py 8080
```
在浏览器打开：[http://127.0.0.1:8080](http://127.0.0.1:8080)

---

### 方式二：Electron 桌面客户端模式

如果你希望作为独立的桌面 Native 窗口运行：

```bash
cd ChinaK12BookDownLoader
npm install
npm start
```
系统将自动拉起桌面应用窗口。
