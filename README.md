# ChinaK12BookDownLoader

> **国家中小学智慧教育平台 K12 教材可视化批量下载器与版本管理系统**  
> **100% 纯 JavaScript / Node.js / Electron 原生实现，零 Python 依赖！**  
> 界面精简直观、极简暗黑质感，支持按学段/学科/版本多维级联筛选、**一键全选当前筛选结果批量下载**、**实时下载管理器抽屉（带速率与进度）**、**本地同名版本跳过**、**官方同名多版本自动优选最新在用版**，以及**官方下架旧版教材安全自动归档至 `History/` 镜像目录（同名覆盖替换）**。

---

## 🌟 核心特性

1. **纯 Node.js / 原生 Web 架构，零 Python 依赖**：
   - 全套后端 API、静态托管与下载并发引擎均采用 Node.js 原生技术栈实现；
   - 用户与开发者无需配置 Python 或安装额外 Python 库，开箱即用。

2. **强制指定下载根目录（China12Books）**：
   - 顶部提供醒目的目录配置栏，默认绑定或自由选择你的课本存放根目录；
   - **未设置目录时强制禁止下载**并提供高亮预警，避免散落下载到未预期路径。

3. **一键全量 / 筛选结果批量下载**：
   - 不再受限于“仅能下载当前页数十条”；
   - 点击 **“全选筛选结果 (共 X 本)”**，无论是筛选出的 240 本初中数学还是全量 3100+ 本，均可一键全部加入下载队列。

4. **右侧实时下载管理器（任务抽屉面板）**：
   - 点击顶部 **“📥 下载列表”** 即可滑出半透明磨砂抽屉；
   - 实时显示：**排队中、下载中、下载速度（MB/s）、进度条、已完成、失败重试**；
   - 彻底解决“点击下载没有任何反馈反应”的问题。

5. **同名版本秒级跳过与官方在用版优选**：
   - 包含版本号（如 `[2024修订版]`、`[2022修订版]`）的文件名；
   - 遇到官方同年级同学科同名多个文件时，以官方**最新在用版（最新时间戳）为准**；
   - 本地已存在且版本大小相符时，下载队列会自动标记为 `已存在(跳过)`，不耗费任何重复流量。

6. **历史版本安全归档至 `History/` 镜像目录（同名覆盖替换）**：
   - 当官方平台更新换代或重新上传新版时，系统自动将本地旧版课本剪切移动至 `China12Books/History/` 对应的镜像子目录下；
   - 若 `History/` 中已存在同名历史版本，直接覆盖替换；
   - 保证主目录永远只有最新在用教材，历史版本完整镜像备份。

## 🚀 启动与使用方式

### 方式一：Node.js Web 模式（零配置秒开）

```bash
cd ChinaK12BookDownLoader
node server.js 8080
```
在浏览器打开：[http://127.0.0.1:8080](http://127.0.0.1:8080)

---

### 方式二：Electron 桌面客户端模式

如果你希望作为独立的桌面 Native 客户端窗口运行：

```bash
cd ChinaK12BookDownLoader
npm install
npm start
```
系统将自动拉起桌面应用窗口。
